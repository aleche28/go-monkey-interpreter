# MonkeyLang Interpreter

This project is an implementation of the **Monkey** programming language, as described in the book *[Writing an Interpreter in Go](https://interpreterbook.com/)* by Thorsten Ball.

Monkey is a simple, C-like language designed for educational purposes. It includes the following features (as introduced in Chapter 1, p. 5):

- C-like syntax  
- Variable bindings  
- Integers and booleans  
- Arithmetic expressions  
- Built-in functions  
- First-class and higher-order functions  
- Closures  
- String data structure  
- Array data structure  
- Hash data structure  

## Motivation

The main goal of this project is to gain a deeper understanding of how interpreters work—especially the scanning and parsing phases—by implementing them manually. In the past, I’ve only used lexer/parser generators such as **JFlex** and **CUP**, which abstract away much of the low-level logic.

By working through this book, I’m writing the lexer, parser, and evaluator from scratch in Go. This hands-on approach not only helps solidify my understanding of language implementation but also improves my proficiency in Go.

So far, my experience with Go has been limited to completing the **Advent of Code 2025**, so this project provides a more structured and in-depth opportunity to practice and grow.

## Next Steps

After completing the book and this interpreter, I plan to re-implement the entire project in **C#**, the language I use daily at work. This will help me:

- Reinforce my understanding of interpreter design  
- Explore lower-level C# features I don’t typically use  
- Improve my mastery of the language in a practical context  

In the future, I may also explore implementations in other languages, depending on interest and learning goals.
